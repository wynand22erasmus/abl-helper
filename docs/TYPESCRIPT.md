# TypeScript language policy

ABL Helper treats **TypeScript as the only hand-authored language** for Node-based code. Parser-adjacent artifacts use TypeScript wrappers, types, or ESM emit where the underlying runtime is still binary (WASM, Emscripten, or C).

## TypeScript source (maintained)

| Area | Path | Checked by |
|------|------|------------|
| VS Code extension | [`src/**/*.ts`](../src/) | `tsconfig.json`, ESLint, Vitest |
| Repo scripts | [`scripts/**/*.ts`](../scripts/) | `tsconfig.tools.json`, ESLint |
| Root tooling | `esbuild.config.ts`, `eslint.config.ts`, `vitest.config.ts` | `tsconfig.tools.json` |
| ABL grammar (authored) | [`parser/abl/grammar.ts`](../parser/abl/grammar.ts) | `tsconfig.grammar.json`; emits ESM `grammar.js` |
| Parser runtime API | [`parser/runtime/tree-sitter.ts`](../parser/runtime/tree-sitter.ts) | `tsconfig.parser-runtime.json` |
| Scanner contract | [`parser/abl/src/scanner.host.ts`](../parser/abl/src/scanner.host.ts), [`scanner.manifest.ts`](../parser/abl/src/scanner.manifest.ts) | `tsconfig.grammar.json`; `npm run check:scanner` |
| WASM manifest | [`src/assets/wasm-manifest.ts`](../src/assets/wasm-manifest.ts) | `tsconfig.json` |

### Compile pipeline (TypeScript → JavaScript)

| Step | Command | Output |
|------|---------|--------|
| Extension bundle (ESM) | `npm run compile:extension` | `out/extension.js` |
| Extension sources (per-file ESM) | `npm run compile:src` | `out/emit/**/*.js` |
| Repo scripts | `npm run compile:scripts` | `out/scripts/**/*.js` |
| ABL grammar for tree-sitter | `npm run compile:grammar` | `parser/abl/grammar.js` (**ESM**) + scanner.c ↔ host ↔ externals check |
| Scanner contract only | `npm run check:scanner` | Validates `scanner.c` exists and matches host + `grammar.ts` |
| Parser runtime | `npm run compile:parser-runtime` | `parser/runtime/index.js`, `tree-sitter.js` |

`npm run build` runs TextMate generation, full `compile`, then `build:parser` (artifact verify + WASM copy).

### Commands

```bash
npm run compile
npm run typecheck
npm run check:typescript-only
npm run lint
npm run audit:languages
npm run check:scanner
```

## Module system (ESM)

- Root [`package.json`](../package.json): `"type": "module"`.
- Extension: [`out/extension.js`](../out/extension.js) (esbuild ESM).
- Grammar: [`parser/abl/grammar.js`](../parser/abl/grammar.js) — ESM emit from `grammar.ts` (tree-sitter-cli **0.24.7+**).
- Runtime: [`parser/runtime/tree-sitter.ts`](../parser/runtime/tree-sitter.ts) is the canonical ESM entry (dynamic `import()` of [`tree-sitter.cjs`](../parser/runtime/tree-sitter.cjs)). [`index.ts`](../parser/runtime/index.ts) re-exports via dynamic import of compiled `tree-sitter.js` only.

| Layer | Format | Notes |
|-------|--------|--------|
| Extension + scripts | ESM | Authored and compiled as ESM |
| `grammar.js` | ESM | Generated; not hand-written |
| `tree-sitter.cjs` | CommonJS | Vendored Emscripten only; no TS source |
| `scanner.c` | C | Required for WASM external scanner; [`scanner.host.ts`](../parser/abl/src/scanner.host.ts) is the typed host contract (C cannot be pure TS for `build-wasm`) |

## Artifacts that cannot become TypeScript source

| Path | Role |
|------|------|
| `parser/runtime/tree-sitter.cjs` | Vendored Emscripten binary binding |
| `*.wasm` | Compiled parser binaries |
| `parser/abl/src/scanner.c` | tree-sitter external scanner (compiled into ABL WASM) |
| `syntaxes/*.tmLanguage.json` | VS Code TextMate grammars |
| `snippets/*.code-snippets` | VS Code snippets |
| `resources/check-syntax.p` | OpenEdge batch runner |
| `parser/abl/src/grammar.json`, `node-types.json` | Generated by `tree-sitter generate`; typed via [`grammar-metadata.d.ts`](../parser/abl/src/grammar-metadata.d.ts) |

## Adding new code

- Use `.ts` under `src/` or `scripts/`.
- Do not add hand-written `.js` under `src/` or `scripts/`.
- Grammar: edit `parser/abl/grammar.ts` → `npm run compile:grammar` → `tree-sitter generate` in `parser/abl/` when rebuilding WASM.
- External scanner: edit `parser/abl/src/scanner.c`; update [`scanner.host.ts`](../parser/abl/src/scanner.host.ts) when token kinds or `externals` change; run `npm run check:scanner`.
