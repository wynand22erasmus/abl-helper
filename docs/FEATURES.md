# ABL Helper — Features Reference

Comprehensive inventory of what **ABL Helper** implements today, what is intentionally **out of scope**, and what could realistically be added next. Sources: [README](../README.md), [CHANGELOG](../CHANGELOG.md), [package.json](../package.json), [extension entry](../src/extension.ts), research notes, and comparison with Riverside LSP, ZExt, CABL, and related extensions.

**Version baseline:** `package.json` **0.1.0** (2026-05-20). **Current `main`** also includes unreleased work listed in CHANGELOG *Unreleased* (autocomplete, snippets). Treat this document as describing **current repository state**, not only the last tagged marketplace release.

---

## 1. Executive summary

**ABL Helper** is a Visual Studio Code extension for **OpenEdge ABL** (`.p`, `.cls`, `.w`, `.i`). It targets developers who want **lightweight editing support** without installing a full Java language server or SonarQube stack.

| Pillar | What you get |
|--------|----------------|
| **Editor** | TextMate syntax (base + 12.8 research injection), language configuration, snippets |
| **Structure** | Document outline via [tree-sitter-abl](https://github.com/eglekaz/tree-sitter-abl) (bundled WASM + web-tree-sitter) |
| **Intelligence (local)** | Keyword + in-file symbol completion; no database schema yet |
| **Format** | Tier A (safe): trim whitespace, keyword case; Tier B (experimental): minimal tree-sitter pass |
| **OpenEdge** | Check syntax via `_progres -b -p` and a helper procedure → Problems panel |
| **Quality** | TypeScript-only extension source, Vitest unit tests, ADE corpus smoke tests, GitHub Actions CI, committed `abl-helper-dev.vsix` |

**Design stance:** complement, not replace, [Riverside OpenEdge ABL LSP](https://marketplace.visualstudio.com/items?itemName=RiversideSoftware.openedge-abl-lsp), [ZExt](https://marketplace.visualstudio.com/items?itemName=EzequielGandolfi.openedge-zext), and [CABL (SonarLint ABL)](https://marketplace.visualstudio.com/items?itemName=RiversideSoftware.sonarlint-abl). Disable overlapping features when running multiple ABL extensions.

## 2. Implemented features

### 2.1 Editor and language registration

| Feature | Details |
|---------|---------|
| **Language id** | `abl` — aliases OpenEdge ABL, ABL, Progress |
| **File extensions** | `.p`, `.cls`, `.w`, `.i` |
| **Activation** | `onLanguage:abl` |
| **VS Code engine** | `^1.85.0` |
| **Language configuration** | [`language-configuration.json`](../language-configuration.json): `//` and `/* */` comments; bracket/auto-close/surround pairs; `//#region` / `//#endregion` folding markers; regex-based indent increase/decrease on block keywords |
| **Format on save default** | Disabled for `[abl]` — legacy codebases can be large; user must opt in |

### 2.2 Syntax highlighting

| Layer | File | Origin |
|-------|------|--------|
| **Base grammar** | `syntaxes/abl.tmLanguage.json` | MIT [chriscamicas/abl-tmlanguage](https://github.com/chriscamicas/abl-tmlanguage) |
| **Research injection** | `syntaxes/research-injection.tmLanguage.json` | Generated by `npm run grammar:build` from OpenEdge 12.8 research |

**Research-driven scopes** (see [syntax-highlighting-research.md](syntax-highlighting-research.md)):

- Reserved keywords (`resources/abl-reserved-keywords.txt`) → `keyword.control.reserved.abl`
- Statement/OO tokens (`resources/research-statement-keywords-128.txt`) → `keyword.control.statement.abl`
- Preprocessor: `&WEBSTREAM`, built-in `{&…}` (e.g. SpeedScript `{&DISPLAY}`, `{&OUT}`)
- .NET inner type `+` → `punctuation.separator.type.abl`
- Keyword-index operators → `keyword.operator.abl`

**Tests:** `src/test/grammar.test.ts` — TextMate tokenization against expected scopes (base + merged injection).

### 2.3 Document outline (symbols)

- **Provider:** `DocumentSymbolProvider` in [`src/extension.ts`](../src/extension.ts)
- **Parser:** tree-sitter-abl via [`src/ablParser.ts`](../src/ablParser.ts) — bundled **WASM** (`web-tree-sitter` + `src/assets/*.wasm` → `out/assets/`) → **none** (empty outline)
- **Symbol kinds:** class, interface, procedure, function, method, constructor, destructor, enum (+ members), variables, properties, parameters, events, temp-table/buffer/dataset and other DEFINE types, includes, USING, ON triggers, labeled DO/REPEAT/FOR blocks ([`src/symbols.ts`](../src/symbols.ts))
- **Setting:** `ablHelper.outline.debounceMs` (default 200) — reserved for future debouncing; outline re-parses on provider invocation
- **Command:** **ABL Helper: Reload Tree-sitter Parser** — resets WASM parser after load issues

### 2.4 Autocomplete

| Source | Content |
|--------|---------|
| **Keywords** | [`resources/abl-keywords.txt`](../resources/abl-keywords.txt) via [`src/keywords.ts`](../src/keywords.ts) (chriscamicas list + abbreviation forms) |
| **Symbols** | Same tree-sitter walk as outline — procedures, methods, classes, etc. in current file |
| **Limits** | Up to 80 keyword + 40 symbol items; prefix filter on typed word |
| **Not included** | Database tables/fields, include path resolution, cross-file symbols |

**Status:** shipped on current `main`; listed under CHANGELOG *Unreleased* until next version bump.

### 2.5 Snippets

- **File:** [`snippets/abl.code-snippets`](../snippets/abl.code-snippets)
- **Constructs:** procedure, function, class, method, `defvar`, `foreach`, `if`, `run`, include `{file.i}`

### 2.6 Formatting

#### Tier A (default, text-based)

| Capability | Command / setting |
|------------|-------------------|
| Trim trailing whitespace | **ABL Helper: Trim Trailing Whitespace**; `ablHelper.format.trimTrailingWhitespace` on Format Document |
| Keyword upper/lower | **ABL Helper: Format Keywords (Upper/Lower Case)**; `ablHelper.format.keywordCaseOnFormatDocument`: `none` / `upper` / `lower` |
| Implementation | [`src/formatters/tierA.ts`](../src/formatters/tierA.ts) — word-boundary replace against keyword set |

#### Tier B (experimental, tree-sitter)

| Capability | Setting |
|------------|---------|
| Minimal structural pass | `ablHelper.format.enableTreeSitterPass` (default **false**) |
| Current behavior | Inserts newline before `THEN` on same line as `IF` when tree node is `if_statement` |
| Risk | Documented in README — prefer Format Selection or keyword-only commands on legacy code |

**Provider:** `DocumentFormattingEditProvider` — full-document replace (Tier A then optional Tier B).

### 2.7 OpenEdge integration — check syntax

| Step | Behavior |
|------|----------|
| **Command** | **ABL Helper: Check Syntax** (`ablHelper.checkSyntax`) |
| **Runtime** | Spawns `ablHelper.batchExecutable` (default `_progres`) under `DLC/bin` with `-b -p` |
| **Helper** | [`resources/check-syntax.p`](../resources/check-syntax.p) — copied to `out/resources/` on build |
| **Env** | `ABL_CHECK_FILE`, listing path; PROPATH from settings + workspace folder |
| **Output** | **ABL Helper** output channel; diagnostics in collection `ablHelper` |
| **Parser** | [`src/checkSyntax.ts`](../src/checkSyntax.ts) — `** Line N **`, `(N:col)`, `Line N:` listing patterns |

**Settings:** `ablHelper.dlcPath`, `propath`, `parameterFiles`, `workingDirectory`, `checkSyntaxExtraArgs`, `batchExecutable`.

**Requirements:** OpenEdge 11.7+ with developer license; `DLC` or `ablHelper.dlcPath`. Not required for highlight/outline/format Tier A.

### 2.8 Commands (registered)

| Command id | Title |
|------------|-------|
| `ablHelper.checkSyntax` | ABL Helper: Check Syntax |
| `ablHelper.formatKeywordsUpper` | ABL Helper: Format Keywords (Upper Case) |
| `ablHelper.formatKeywordsLower` | ABL Helper: Format Keywords (Lower Case) |
| `ablHelper.formatTrimRight` | ABL Helper: Trim Trailing Whitespace |
| `ablHelper.showOutput` | ABL Helper: Show Output |
| `ablHelper.restartParser` | ABL Helper: Reload Tree-sitter Parser |

No default keybindings in `package.json`; users bind via Keyboard Shortcuts.

### 2.9 Build, tooling, and repository

| Area | Implementation |
|------|----------------|
| **Language** | TypeScript only under `src/` and `scripts/` (ESLint + `check:typescript-only` CI guard) |
| **Bundler** | esbuild → `out/extension.js`; assets in `out/resources/` |
| **Root tooling** | [tsx](https://github.com/privatenumber/tsx) — `esbuild.config.ts`, `eslint.config.ts`, `scripts/*.ts` without separate compile |
| **Grammar build** | `scripts/build-syntax-from-research.ts` |
| **WASM fetch** | `npm run fetch:parser-wasm` |
| **Package** | `npm run package` → **`abl-helper-dev.vsix`** at repo root (committed for quick install) |
| **Unit tests** | Vitest: symbols, completion, check-syntax parser, grammar scopes |
| **ADE corpus** | `npm run corpus:sync` → `corpus/ade`; `npm run test:corpus` — deterministic sample parse smoke (pinned ADE commit in CI) |
| **CI** | `.github/workflows/ci.yml` — build, typecheck, lint, test; separate **corpus** job with `progress/ADE` checkout |
| **Third-party** | web-tree-sitter, tree-sitter + tree-sitter-abl WASM; vscode-textmate + oniguruma for grammar tests (see README Credits) |

**Corpus settings:** `ablHelper.corpus.adeRoot`, `maxFileBytes`, `sampleSize`.

## 3. Explicitly out of scope

Use specialized extensions; ABL Helper will not replicate these in v1.

| Capability | Use instead | Notes |
|------------|-------------|-------|
| **Full language server** (go-to-def, rename, rich hover, project-wide refs) | [Riverside openedge-abl-lsp](https://marketplace.visualstudio.com/items?itemName=RiversideSoftware.openedge-abl-lsp) | Java-based; `openedge-project.json` |
| **Debugger** (legacy + PASOE), `launch.json` templates | Riverside LSP / ZExt | Attach, breakpoints, run configs |
| **Compile/deploy pipeline**, AppBuilder, Data Dictionary, Speedscript | ZExt, Camicas ecosystem, PCT/Ant | Beyond check-syntax subprocess |
| **SonarQube / CABL rule packs**, metrics, CPD, coverage UI | [CABL (sonarlint-abl)](https://marketplace.visualstudio.com/items?itemName=RiversideSoftware.sonarlint-abl) | Requires LSP + `openedge-project.json`; commercial rules |
| **Class browser** + `catalog.json` | [Consultingwerk Class Browser](https://marketplace.visualstudio.com/items?itemName=ConsultingwerkApplicationModernizationSolutionsLtd.classbrowser) | Catalog-driven navigation |
| **Extension API** for other tools (`getProjectInfo`, `compile`, `getSchema`) | Riverside LSP | Coupled to their project model |

**Research pointers:**

- OpenEdge 12.8 language reference: [research-openedge-abl-reference-128.md](research-openedge-abl-reference-128.md)
- CABL / SonarLint behaviors: [research-cabl-sonarlint-validations.md](research-cabl-sonarlint-validations.md)
- Highlighting vs lint: [syntax-highlighting-research.md](syntax-highlighting-research.md) — diagnostics are not TextMate concerns

**Coexistence:** Install ABL Helper alongside Riverside LSP or ZExt; disable duplicate format-on-save and avoid conflicting grammars if both register `abl`.

## 4. Realistic future features

Prioritized from README checklist, roadmap phases, and research docs. Effort assumes staying **TypeScript + tree-sitter + optional OpenEdge subprocess** (no full LSP rewrite).

### 4.1 Near-term (Phase 2 — language intelligence)

| Feature | Rationale | Main dependency |
|---------|-----------|-----------------|
| **Richer check-syntax diagnostics** | Map individual compiler warnings (e.g. **18494** abbreviated keywords) from listing | OpenEdge install; parser improvements in `checkSyntax.ts` |
| **Include suggestions on `{`** | High UX value; PROPATH + file glob | Workspace folders, `ablHelper.propath` |
| **Go to definition (local + includes)** | Includes and in-file symbols first | tree-sitter + PROPATH resolution |
| **Hover (basic)** | Variable/type hints from parse tree | tree-sitter; schema later |
| **Expand keyword lists** | Full [Keyword Index](https://docs.progress.com/bundle/openedge-abl-reference-128/page/Keyword-Index.html) | Regenerate `resources/*.txt`, grammar injection |
| **More snippets** | Patterns from ADE corpus / team templates | Editorial |

### 4.2 Mid-term (Phase 3 — project and OpenEdge workflows)

| Feature | Rationale | Main dependency |
|---------|-----------|-----------------|
| **`openedge-project.json` / `.abl-helper.json`** | Align with LSP/CABL project marker | JSON schema read; PROPATH, DB, build dirs |
| **Compile current file** | Beyond check-syntax; xref/listing options | `_progres` / PCT-style args |
| **Run procedure** | Batch (`_progres`) and interactive (`prowin`) | DLC, working dir, `-pf` |
| **Deploy source / r-code** | Optional hooks | User scripts / OE install |
| **Startup procedure** for check-syntax | Project context | Parameter files + project config |
| **Autocomplete: tables/fields** | Dictionary / `.df` when configured | Schema files or DB connection metadata |

### 4.3 Later (Phase 4 — format and lint depth)

| Feature | Rationale | Main dependency |
|---------|-----------|-----------------|
| **Tier B formatting (Baltic-style)** | assign, if, case, for, block, temp-table, `using` | tree-sitter edits + per-construct settings |
| **`ablHelper.format.*` per construct** | User-tunable style | Settings schema + formatter modules |
| **Lightweight lint (Tier 1 from CABL research)** | `ClumsySyntax`-style: `END` + period, statement terminators, METHOD `.` vs `:` | tree-sitter AST walks — see [research-cabl-sonarlint-validations.md](research-cabl-sonarlint-validations.md) § Mappable future diagnostics |
| **require-full-keywords diagnostic** | Compiler warning 18494 | Token compare vs full keyword set |
| **Preprocessor column-0 rule** | 12.8 preprocessor placement | Lexer/line-based check |
| **Dictionary / schema awareness** | Qualified fields (14789), schema casing (14786) | `.df` or project DB config |

### 4.4 Release hardening (Phase 5)

| Feature | Rationale | Main dependency |
|---------|-----------|-----------------|
| **VS Code Marketplace publish** | Public distribution | Publisher account, vsce release pipeline |
| **Compatibility matrix** | OE 11.7 / 12.2 / 12.8 | CI matrix or manual smoke |
| **Broader ADE corpus assertions** | Formatter idempotence on allowlist | Corpus maintenance, pinned ADE bump |
| **Coexistence documentation** | Which features to disable per combo | Docs only |

### 4.5 Integration options (not default path)

From CABL research — choose one if deep analysis is required:

1. **Delegate** — document install of CABL + Riverside LSP; ABL Helper stays editor-focused.
2. **Subset linter** — port OSS Proparse-style checks where tree-sitter suffices.
3. **LSP bridge** — only if project direction changes; large scope.

## 6. Dependencies and requirements by feature area

| Feature area | User / runtime requirements | Repo / dev dependencies |
|--------------|----------------------------|-------------------------|
| **Syntax highlighting** | VS Code 1.85+ only | chriscamicas grammar; `grammar:build` script; research txt files |
| **Language configuration** | VS Code only | `language-configuration.json` |
| **Outline** | WASM in `src/assets/` (bundled `web-tree-sitter`, warmed on activate) | `web-tree-sitter`, tree-sitter + tree-sitter-abl WASM |
| **Autocomplete** | Same as outline (degrades to keywords-only if parser `none`) | `abl-keywords.txt`; `completion.ts` |
| **Snippets** | VS Code only | `snippets/abl.code-snippets` |
| **Tier A format** | VS Code only | `abl-keywords.txt` for case rules |
| **Tier B format** | Parser available | tree-sitter + `enableTreeSitterPass` |
| **Check syntax** | OpenEdge DLC, `_progres`, developer license; `DLC` or `ablHelper.dlcPath` | `check-syntax.p`; Node `child_process` |
| **ADE corpus tests** | Optional local `corpus/ade` or CI checkout | Vitest; pinned `ADE_PIN` in workflow |
| **Build extension** | Node.js 20+, npm | esbuild, tsx, TypeScript, vsce |
| **Grammar tests** | Node only | vscode-textmate, vscode-oniguruma |

**Environment variables:**

| Variable | Used by |
|----------|---------|
| `DLC` | OpenEdge root when `ablHelper.dlcPath` empty |
| `ADE_ROOT` | Corpus tests when `ablHelper.corpus.adeRoot` empty |
